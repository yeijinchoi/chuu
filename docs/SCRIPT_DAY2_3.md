## 0. 재방문 대사 규칙 (같은 손님이 다시 왔을 때)

- 손님은 **지난 방문을 기억한다.** 두 번째 방문부터는 첫 방문 대사를 그대로 반복하지 않는다.
- 카드의 방문 횟수(`visits`)로 고른다: 2회째 = `returns["2"]`, 3회째 이상 = `returns["3"]`. 해당 키가 없으면 첫 방문 대사로 돌아간다.
- 바뀌는 대사: `opening`(첫 대사), `openingRegular`(단골 등록된 손님일 때), `askCategory` · `askOccasion` · `askBudget` · `observe` · `success` · `fail` · `farewell`. 안 적힌 키는 첫 방문 것을 쓴다.
- 새벽 손님도 같다. 수칙과 위반 대사는 바꾸지 않는다(규칙은 그대로이므로).
- **같은 물건을 또 살 수 있다.** 재방문 손님의 품목·색·예산 프로필은 그대로이고, 대사가 "같은 걸로 한 벌 더" 같은 이유를 댄다.
- 한 손님이 하루에 두 번 오지 않는다. 재방문 슬롯은 **전날 판매에 성공한 손님**이 대상이다.

## 4. 아이폰 알림·메모 사양 (실제 iOS와 비슷하게)

> 참고 방향: 실제 스마트폰 알림 배너와 메모 앱의 구조. 브랜드 로고·"iMessage" 같은 상표는 쓰지 않는다.

### 4-1. 알림 배너 해부
- **위치**: 폰 화면 **맨 위**(카메라 섬 바로 아래)에서 아래로 내려온다. 폰 안 컨텐츠 위를 덮되 높이는 **최대 64px**(2줄까지).
- **모양**: 둥근 모서리 18px 카드, 반투명 어두운 판(`dusk` 90%)과 1px 밝은 테두리(`stone`), 아주 옅은 그림자. 폭 = 화면 폭 − 16.
- **구성** (왼→오): 앱 아이콘 36×36(둥근 8px) · 가운데 두 줄 [**앱 이름** 작게 대문자 느낌 + 오른쪽 시각 "지금"] / [**보낸 사람** 굵게] / [내용 한 줄 말줄임] · 오른쪽 위 시각.
- **동작**: 위에서 슬라이드 인 0.35초 → 4초 머무름 → 위로 슬라이드 아웃. 탭하면 해당 대화/메모를 연다. 위로 쓸어 올리면 바로 닫힌다. 여러 개가 오면 **아래로 쌓이지 않고** 새 알림이 이전 것을 밀어 올리며 교체(최대 2개가 겹쳐 보임).
- **알림 센터**: 화면 위에서 아래로 끌면 놓친 알림 목록(그룹: 앱별). 구현은 4일차 이후.
- **소리**: `phone_buzz`(문자), `phone_buzz` ×2(04:44), 알림음은 이벤트만.
- **발신 앱 아이콘**: 메시지(말풍선), 메모(노트), 팁(전구), 점장 로즈 = 메시지 앱, 한서진 = 메시지 앱.

### 4-2. 튜토리얼은 알림으로 (화면을 가리지 않는다)
지금의 **큰 말풍선 박스(폰·장면 위를 덮는 것)를 없앤다.** 모든 튜토리얼은 알림 배너로 보낸다.
- 발신 앱: **팁**(전구 아이콘), 보낸 사람 "메종 뤼미에르". 내용은 한 줄(최대 2줄), 4초 후 사라짐. 탭하면 메모의 「접객 팁」 메모로 이동해 전체 설명을 읽는다.
- 폰이 닫혀 있는 응대 장면에서는 **장면 오른쪽 위 구석**에 같은 모양의 작은 알림(폭 220px)으로 나온다. 장면 중앙을 가리지 않는다.
- 같은 튜토리얼은 한 번만. 모든 튜토리얼 문장은 `strings.ko.json`의 `tutorial.*`(변경 없음).

### 4-3. 메모 앱 (아이폰 메모 구조)
- **폴더 화면**: 큰 제목 "폴더", 항목 `근무 수칙`, `접객 팁`, `손님 메모`, `삭제된 항목`(회색, 비어 있음). 각 줄 오른쪽에 개수와 `›`.
- **목록 화면**: `‹ 폴더`, 큰 제목 폴더 이름, 검색 칸. 날짜 그룹 머리말("오늘", "어제") 아래 행 = **굵은 제목 · 날짜(작게) + 첫 줄 미리보기(회색)**. 가장 위 메모가 "새 메모"면 오른쪽에 점 하나.
- **상세 화면**: `‹ 근무 수칙`, 오른쪽 위 공유·더보기 아이콘(비활성), 상단에 날짜("2026년 11월 23일 오후 12:31"), 첫 줄은 큰 제목, 나머지는 본문. **글꼴 크기: 제목 20px / 본문 14px, 줄 간격 1.5**. 번호 목록은 `1.` 형태로 들여쓰기. 찢긴 6번은 취소선 + 오른쪽 끝이 들쭉날쭉.
- **색**: 낮 = `paper` 바탕 + 줄 없는 깨끗한 종이, 항목 구분선 `sep`(옅은 회색). 새벽 = `shadow` 바탕 + `paper` 글자(검은 수첩과 같은 다크).
- **편집 상태**: 읽기 전용(커서·키보드 없음).
- **새 메모 알림**: 메모가 추가되면 메모 앱 아이콘에 빨간 점 배지, 탭하면 해당 메모로.

### 4-4. 업무폰 홈 화면 보강
- 앱 아이콘 배지: 메시지(읽지 않은 수), 메모(새 메모 수).
- 새 앱 아이콘 **갤러리**(사진 앱, 3일차 차은호 사진용), **팁**(전구).
- 잠금화면 알림(옵션, 4일차 이후).
