# 디자인 시스템 — "더스크 모노"

> `ui-design` 절차로 정의했고 HUD·패널 규칙에는 `desktop-uiux-pro`를 적용했다. 마지막 다듬기는 `impeccable`로 한다.
> 모든 색·간격·글꼴은 여기서 정의한 **토큰**으로만 쓴다. 컴포넌트에 hex 값을 직접 쓰지 않는다.

---

## 1. 제품 유형과 비주얼 방향

- **제품 유형**: 내러티브 접객 시뮬레이션 게임. 화면은 하나이고 UI 비중이 높다.
- **스타일**: **저해상도 절제 도트**. 90년대 초 어드벤처 게임처럼 형태를 단순하게 그린다. 화면 대부분은 탁한 회보라 무채색이고, 색은 명품의 포인트(로즈 가방, 황동 프레임)와 이상 징후에만 조금 넣는다. 화사함 대신 **조용하고 쓸쓸한 명품관**이 기본 톤이다.
- **색 사용 원칙**: 장면 면적의 90% 이상은 무채색 8단계로 그린다. 포인트 색은 한 장면에 **최대 2가지**, 면적은 **10% 이하**로 쓴다. 색이 드물어야 색이 나타나는 순간이 무섭다(예: 회색 매장에 혼자 로즈색인 분홍 코트).
- **피할 것**: 채도 높은 네온색, 글로우, 그라데이션, AI 기본 룩(Inter, 보라 그라데이션, 둥근 카드), 블러 그림자, 둥근 모서리, 디테일 과잉. 참고 이미지: `docs/concept/v2-*.png` (v1은 너무 화려해서 기각했다).
- **다크 모드만 쓴다**: 매장은 밤의 무대이고, 공포 연출이 어두운 바탕을 전제로 한다. 라이트 테마는 만들지 않는다. 대신 분위기 테마(`data-mood`)를 바꾼다(§3).

### 디자인 다이얼
| 다이얼 | 값 | 이유 |
|---|---|---|
| DESIGN_VARIANCE | 5 | 장면은 정면 대칭, UI는 비대칭 배치(폰은 오른쪽, 쪽지는 왼쪽 아래) |
| MOTION_INTENSITY | 6 | 평소엔 조용하고, 공포 순간에만 강하다 |
| VISUAL_DENSITY | 4 | 대사와 선택지에 집중한다. HUD는 한 줄 |

## 2. 무대와 해상도

> 개정: 무대는 960×540, 장면 뷰포트는 640×360(장면 320×180의 2배). 아래 표의 640×360 무대 값은 이전 배치 기준이다. §7을 따른다.

| 항목 | 값 |
|---|---|
| 장면 캔버스 | **320×180** 도트 |
| UI 무대(stage) | **640×360** 논리 px. 캔버스는 2배로 깔린다 |
| 화면 맞춤 | stage를 `scale = max(1, floor(min(vw/640, vh/360)))`로 정수배 확대. 창이 640×360보다 작으면 비율을 유지한 채 소수 배율 허용 |
| 렌더링 | `image-rendering: pixelated`, 캔버스 `imageSmoothingEnabled = false` |
| 그리드 | UI는 **2px 그리드**(장면의 1도트)에 맞춘다 |

### 3-1-1. 도트 기법 (고도화 기준)
- **재질마다 최소 3톤**(그림자 / 기본 / 하이라이트). 오후 광원은 위쪽 가운데 샹들리에, 새벽 광원은 카운터 스탠드.
- **접지 그림자**: 물체가 면에 닿는 곳(선반 위 가방, 마네킹 받침, 카운터 위 손)에 어두운 도트 한 줄.
- **선택적 외곽선(sel-out)**: 바깥 윤곽은 인접한 채움색의 어두운 단계로 그린다. `ink`는 밝은 배경과 맞닿는 곳과 가장 깊은 틈에만 쓴다.
- **수동 안티에일리어싱**: 곡선의 계단 꺾임마다 중간 톤 1도트(머리, 가방, 진주, 샹들리에 팔).
- **얼굴**: 손님 상체 최대 약 56×96. 눈 2×2~3×2에 하이라이트 1도트, 눈썹, 코 그림자 1~2도트, 성격에 맞는 입 모양, 피부 3톤.
- **머리카락**은 덩어리 가닥과 하이라이트 띠로, **옷**은 주름 2~3줄과 깃·단추·소매로 표현한다.
- **환경 질감**: 퀼팅 벽의 바늘땀과 교차점 단추, 천장 모서리 쪽 디더 음영, 대리석 바닥의 옅은 결, 선반 앞면 하이라이트와 밑면 그림자, 유리 카운터의 사선 반사, 새벽 스탠드 빛 웅덩이의 디더 경계.
- **디더링은 2×2 체커만**, 그라데이션과 빛 경계에만 쓴다. 잡음처럼 흩뿌리지 않는다.

### 3-3. 교대 테마 — `<html data-shift="afternoon|dawn">`
| shift | 화면 |
|---|---|
| `afternoon` | 매장 조명이 고르게 켜져 있다. 포인트 색은 가방 몇 개(rose)와 금속 장식(brass) 정도. 공포 연출 없음 |
| `dawn` | 샹들리에가 꺼지고 카운터 스탠드 하나만 켜진다. 빛 반경 밖은 무채색이 한 단계 어두워진다. 진열장에는 기괴한 아이템이 놓인다. 기본 mood는 `uneasy`. 업무폰은 검은 수첩 화면(`shadow` 바탕, `paper` 글자)으로 바뀐다 |

### 3-4. 분위기 테마 — `<html data-mood="calm|uneasy|dread|breach">`
| mood | 바뀌는 토큰 |
|---|---|
| `calm` | 기본값 |
| `uneasy` (새벽 기본) | 포인트 색이 빠지기 시작한다: `brass`→`mist`, `rose`는 그대로. 무채색이 한 단계 어두워진다 |
| `dread` / `collapse` | 포인트 색은 `wine`만 남고 나머지는 무채색으로 바뀐다. 무채색이 두 단계 어두워진다 |
| `breach` (위반 1.2초) | 화면 전체를 `ink`/`wine` 2색으로 바꾸고, 하이라이트만 `paper`로 남긴다 |

장면 캔버스에도 같은 mood를 전달한다. 캔버스는 팔레트 맵을 바꿔서 같은 효과를 낸다(`TECH_SPEC.md` §6).

## 4. 타이포그래피 — Galmuri (OFL, 로컬 번들)

| 역할 | 글꼴 | stage px | 행간 |
|---|---|---|---|
| 타이틀 로고 | Galmuri14 | 28 | 1.2 |
| 패널 제목, 이름표 | Galmuri11 Bold | 11 | 1.4 |
| 본문, 대사, 선택지 | Galmuri11 | 11 | 16px (1.45) |
| 숫자 (금액, 시각) | GalmuriMono11 | 11 | 1.4 |
| 키 태그, 작은 라벨 | Galmuri9 | 9 | 1.3 |

- 글자 크기는 **11의 배수 또는 위 표의 값**만 쓴다. 비트맵 격자가 깨지지 않게 하기 위해서다.
- 금액은 `₩2,300,000` 형식, 시각은 `14:00` 형식. 둘 다 Mono 글꼴을 쓴다.
- 대사는 타자기 효과로 초당 40자 출력. `Space`나 클릭을 누르면 전체를 바로 표시한다.

## 5. 간격·모양·그림자

| 토큰 | 값 |
|---|---|
| `--space-1` … `--space-6` | 2 / 4 / 8 / 12 / 16 / 24 px |
| `--border-w` | 2px |
| `--radius` | 0. 모서리는 2px 계단 노치(`clip-path`)로 처리한다 |
| `--shadow-hard` | `0 2px 0 var(--ink)`. 블러 0 |
| `--z-scene` / `--z-hud` / `--z-dialogue` / `--z-overlay` / `--z-phone` / `--z-modal` / `--z-fx` | 0 / 10 / 20 / 30 / 40 / 50 / 60 |

**럭스 패널**(대화창, 정산서, 상품 카드): 바깥 2px `--color-trim`, 안쪽 2px `--color-surface-raised`, 위쪽 안쪽에 1도트 `--color-trim-shadow` 하이라이트, 모서리 계단 노치.

## 6. 모션 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| `--dur-fast` | 80ms | 버튼 눌림 |
| `--dur-base` | 160ms | 패널 열기 |
| `--dur-slow` | 320ms | 폰 슬라이드, 손님 등장 |
| `--ease-pixel` | `steps(4, end)` | UI 등장. 도트 느낌의 끊기는 움직임 |
| `--ease-out` | `cubic-bezier(.2,.8,.2,1)` | 폰 슬라이드 |

- 손님 등장: 출입문에서 카운터까지 4프레임 걸음 + 페이드 없이 등장.
- `prefers-reduced-motion`: 슬라이드는 즉시 표시, 흔들림 없음, 타자기 효과 끔.

## 7. 화면 배치 — 세 개의 프레임 (stage 960×540)

- 선택지: 뷰포트 안 (448, 200) 184×152, 보조 프레임 버튼 4개(높이 32, 간격 6).
- 단계 표시와 하트: 뷰포트 왼쪽 위 (8,8), 작은 명판 위에.
- 수칙 쪽지는 업무폰의 「수칙」 탭으로 옮긴다(`R` 키는 그 탭을 연다).

## 7-1. 프레임 스타일 — "메종 필리그리"

**방향**: 가는 금속선 두 줄 + 모서리의 작은 장식. 두꺼운 금장이나 그라데이션이 아니라, 보석함 안쪽 테두리처럼 **얇고 정교하게**. 참고한 방향은 다크 판타지 UI 팩의 가는 이중선과 모서리 필리그리지만, 문양은 이 게임 것으로 새로 그린다(명품관의 퀼팅 마름모, 진주 알, 열쇠 구멍).

| 요소 | 규칙 |
|---|---|
| 판 바탕 | `shadow`, 모서리 각지게(라운드 없음) |
| 바깥 선 | 1px `brass-dark` |
| 사이 간격 | 1px 바탕 |
| 안쪽 선 | 1px `stone`. 주 프레임은 안쪽 선 한 줄 더(2px 띄워서 `dusk`) |
| 하이라이트 | 장식에만 `brass`·`brass-light` 1도트. 선 전체를 밝히지 않는다 |
| 주 프레임 모서리 | 16×16 필리그리: 안쪽으로 말린 덩굴 두 갈래 + 가운데 진주 한 알(`bone` 1도트 + `paper` 하이라이트) |
| 주 프레임 윗변 가운데 | 명판(cartouche) 장식: 좌우로 가늘어지는 선 + 가운데 작은 마름모(퀼팅 모티브). 응대 프레임 명판에는 `MAISON LUMIÈRE`(Galmuri9, `bone`) |
| 보조 프레임 모서리 | 8×8: 작은 덩굴 한 갈래 또는 모서리 홈(notch) |
| 상품 칸 | 32×32 기준(화면 64×64): 모서리 홈 4개 + 위쪽 가운데 작은 V 장식 |
| 구분선 | 가운데 마름모, 양끝으로 갈수록 1px씩 끊기며 사라지는 선(dither 페이드) |
| 버튼 | 보조 프레임. hover: 안쪽 선이 `brass`로, focus: 모서리 장식이 `brass-light`로, selected: 바탕 `dusk` + 안쪽 선 `rose` 1px |

- **새벽(교대 테마)**: 프레임이 녹슨다. `uneasy` 이상에서 `brass` 계열이 회색으로 바뀌는 mood 규칙을 프레임에도 그대로 적용한다(금속이 빛을 잃는 연출). `breach` 순간에는 프레임 선이 `wine`으로.
- **구현**: 프레임은 코드로 그린 9-slice 이미지다. 시작 때 캔버스로 팔레트 키를 써서 그려 data URL로 만들고, CSS `border-image`로 붙인다(`image-rendering: pixelated`). mood가 바뀌면 다시 생성한다. 크기가 다른 프레임도 같은 9-slice를 늘려 쓴다.

## 7-2. 모바일 세로 배치 (`mobile-uiux-pro` 적용)

> 목업: `docs/concept/ui-mockup-mobile.png` (390×844 기준 세 화면: 응대 / 진열 바텀시트 / 업무폰 바텀시트)

데스크톱 무대(960×540)를 폰 폭으로 줄이면 글자가 6~8px가 되어 읽을 수 없다. 모바일은 **장면 캔버스만 화면 폭에 맞춰 줄이고, 글자·버튼은 CSS px 원래 크기로 흐르는 레이아웃**으로 다시 배치한다.

**전환 조건**: 뷰포트 폭 < 760px 이고 세로 방향이면 모바일 배치. 작은 화면 가로 방향(높이 < 500px)은 "세로로 돌려 주세요" 안내(프레임 안, 회전 아이콘)를 띄운다.

| 영역 | 위치 (위→아래) | 내용 |
|---|---|---|
| 상단 정보 영역 | 상태 명판, 높이 40 | DAY · 시각 · ₩ · 단골 · 평정심 배터리 10칸 (읽기 전용) |
| 응대 프레임 | 화면 폭, 장면 16:9 | 장면 캔버스(폭에 맞춤, `image-rendering: pixelated`), 위에 단계+하트 작은 명판, `MAISON LUMIÈRE` 명판 |
| 대화창 | 장면 아래, 높이 약 110 | 이름표 + 대사(Galmuri14 14px) + 지문(`mist`). 탭하면 넘김 |
| 선택지 | 엄지 영역 | 화면 폭 버튼 4개, 높이 48, 간격 8. 숫자 태그 유지 |
| 하단 탭 바 | 맨 아래, 높이 52 + safe-area | 응대 · 진열 · 업무폰. 업무폰에 새 알림 점(`rose`) |

- 바텀시트는 아래로 끌어 닫는다. 위쪽 장면은 `ink` 55% 덮개로 어둡게.
- safe-area: 상단 정보 영역은 `env(safe-area-inset-top)`, 탭 바와 시트 하단은 `env(safe-area-inset-bottom)`만큼 여백.
- 프레임은 데스크톱과 같은 필리그리 9-slice. 모바일에서는 모서리 장식을 작은 프레임용(8×8)으로 쓰고, 주 프레임(응대·시트)만 진주 장식을 둔다.
- 호버 상태 대신 눌림 상태(`:active`): 안쪽 선 `brass`.

## 8. 컴포넌트와 상태

모든 상호작용 요소는 **default / hover / focus-visible / active / disabled / selected** 상태를 가진다.

| 컴포넌트 | 명세 |
|---|---|
| **ChoiceButton** | 높이 32, 왼쪽에 키 태그 `[1]`(Galmuri9, `--color-trim`). hover: 바탕 `--color-surface-raised`, 테두리 `--color-trim`. selected: 바탕 `--color-accent`, 글자 `--color-accent-text`, 커서 대신 왼쪽 2도트 ▶. focus-visible: 2px `--color-info` 외곽선. disabled: `--color-text-muted`에 이유를 툴팁으로 표시(예: "이미 물어봤어요"). 위험할 수 있는 선택지에도 아무 표시를 하지 않는다. 판단은 플레이어 몫이다 |

## 9. 입력과 키 표시 (데스크톱)

| 키 | 동작 |
|---|---|
| `1`~`4` | 선택지 고르기 |
| `Space` / `Enter` / 클릭 | 대사 넘기기, 전체 표시 |
| `P` | 업무폰 열기/닫기 (문자 영업 단계에는 강제로 열림) |
| `R` | 근무 수칙 쪽지 |
| `Esc` | 오버레이 닫기, 일시정지 메뉴 |

키는 버튼 위 키 태그로 항상 보여 준다. 모든 버튼은 `Tab`으로 포커스할 수 있고, 클릭 영역은 최소 32×32 stage px(실제 화면 2배 기준 64px)이다.

## 10. 장면 아트 가이드 (320×180)

- **구도**: 카운터 뒤에서 정면을 본다. 손님은 카운터 건너편 가운데(x≈160)에 상반신이 보이게 선다.
- **레이어 (뒤→앞)**: 벽(희미한 마름모 퀼팅, dusk/stone) → 선반 3단(가방 9개, 대부분 무채색이고 로즈 2개) → 출입문(오른쪽 뒤, brass 손잡이, 유리는 steel 1도트 하이라이트) → 마네킹 2개(bone, 양쪽 구석) → 전신 거울(왼쪽, brass 프레임. 장식이며 아무것도 비추지 않는다) → 샹들리에(brass 팔 + bone 갓, 빛 번짐 없음) → 체커 바닥(mist/ash, 원근 3단) → **손님** → 카운터(전경, y 132~180, shadow 상판에 brass 선 1줄).
- **세 부서가 한 화면에**: 뒷벽 선반 = 가방, 양쪽 마네킹과 행거 = 의류, 앞쪽 유리 카운터 = 파인주얼리. 제안 카드와 HUD에 부서 라벨(`가방` `의류` `파인주얼리`, Galmuri9)을 붙인다.
- 참고: `docs/concept/v2-01-scene-calm.png`가 기준 구도와 톤이다.
- **도트 규칙**: 외곽선은 `ink`. 빛은 하이라이트 1도트로만 표현하고 글로우는 없다. 디더링은 2×2 체커만 쓴다. 얼굴은 점 눈 2개 + 입 1줄 수준으로 단순하게 그린다.
- **손님 도트**: 약 48×88, 머리 스타일 5종(단발/긴머리/올림머리/짧은머리/포마드), 피부 2톤, 옷 대표색, 액센트 소품. 이상 특성은 덧씌우는 레이어로 그린다(손가락 추가, 서리 맺힌 손, 깜빡이지 않는 눈). 새벽 손님의 이상한 점은 숨기지 않고 바로 보이게 그린다.
