# 공포 연출 레퍼런스 (핀터레스트)

새벽 괴현상(`src/render/scene.ts`의 `APPARITION_SPOTS`)을 만들 때 본 레퍼런스와, 거기서 뽑은 원리. 그림은 남의 작업이라 저장소에 넣지 않고 링크만 둔다.

## 그림 만드는 법 (레퍼런스 수준의 질감)
코드로 찍은 몇 도트짜리 도형은 레퍼런스와 질이 너무 달라서, 손님처럼 그림으로 만든다.
1. 힉스필드에서 새벽 손님 시트(시트 c)를 **그림체 참조**로 4칸 시트를 그린다(레퍼런스 그림은 넣지 않는다: 원리만 가져온다). 평평한 회색 배경.
2. 배경 제거 → `docs/concept/sheets/horror-<a|b>-open.png`, `-alpha.png`
3. 눈이 있는 그림은 같은 시트를 **눈만 감은 그림**으로 한 장 더 그린다 → `horror-<a|b>-closed.png`
4. `python3 tools/import_apparitions.py`: 손님과 같은 팔레트 맞추기·색 수 제한·외곽 처리로 640×360 촘촘한 도트로 줄인다 → `public/art/apparitions/`. 눈 종류는 감은 그림에서 **눈 부분만 잘라** 눈꺼풀 덧그림 두 장을 만든다: `<kind>.lid1.png`(위쪽 절반만 덮은 반쯤 감김 + 눈꺼풀 선), `<kind>.lid2.png`(감김). 머리카락처럼 다시 그려지며 미세하게 달라진 곳은 눈 상자 밖이라 버린다.
5. 렌더러가 장면 위, 손님 뒤에 그린다. 분위기(평정심)에 따라 손님과 같은 색 변화를 받는다. 그림이 없으면 코드 도트로 대신한다.

그림으로 그리는 것: 문틈의 얼굴과 눈 · 바닥에서 올라온 손 · 선반 손가락 · 유리에 붙은 얼굴 · 거울 속 긴 머리 여자 · 거대한 눈 · 어둠 속 여러 눈 · 손자국에서 흘러내리는 피. 코드 도트로 남은 것: 벽 위 두 눈(작게), 문 유리 손자국, 검은 거울, 노이즈 사람(노이즈는 코드가 맞다).

## 뽑은 원리 → 매장에 옮긴 것

| 레퍼런스에서 본 것 | 원리 | 이 게임 (종류 · 단계) |
|---|---|---|
| 평범한 복도 끝에 작게 올라온 하얀 손 하나 | **평범한 장면 속 작은 이상.** 알려 주지 않는다. 플레이어가 "방금 뭐였지?" 하게 | 출입문 앞 바닥에서 올라온 작은 손 (`hallHand` · 평온) |
| 살짝 열린 문틈의 어둠 속 두 눈 | **틈 속의 눈** | 출입문 두 짝 사이가 벌어지고 그 틈에 두 눈 (`doorGapEyes` · 평온) |
| (마네킹 레퍼런스) 무언가 뒤에 숨은 몸의 일부 | **보이지 않는 몸** | 맨 위 선반 너머로 걸친 손가락 넷 (`shelfFingers` · 평온) |
| 창 대신 뚫린 검은 사각형 | **있어야 할 것이 없음** | 거울이 아무것도 비추지 않는 검은 면 (`mirrorVoid` · 평온) |
| 어둠 속 한 쌍의 눈, 흩어진 여러 눈 | 어둠 속 시선 | 벽 위 어둠의 두 눈 (`eyes`), 여러 쌍의 눈 (`eyesMany` · 공포) |
| "YOU'RE FINALLY HERE." 노이즈로 된 사람 | **노이즈 실루엣** (형체가 안정되지 않음) | 마네킹과 선반 사이, 그릴 때마다 노이즈가 바뀌는 사람 모양 (`noiseFigure` · 불안) |
| 창밖에 선 긴 머리 인물, 금 간 거울 속 검은 인물 | **유리 너머의 인물** | 거울 속 얼굴 (`mirrorFace` · 불안), 거울 안에 선 긴 머리 실루엣과 금 (`mirrorFigure` · 공포), 문 유리의 손자국 (`hand` · 불안) |
| 들판 위 하늘을 덮은 거대한 분홍 눈 | **압도하는 크기.** 아껴 둔다 | 벽 위쪽 전체의 거대한 두 눈, 홍채만 로즈 (`giantEyes` · 붕괴 단계에서만) |
| 빨강을 거의 안 쓰다가 한 점만 쓰는 그림들 | **포인트 색은 한 점** | 핏자국만 와인색 (`blood` · 불안) |

## 나오는 방식
- **평온할수록 작고 짧게:** 평온 단계에서는 작은 것만 0.5초 남짓(문틈·손·손가락·검은 거울). 평정심이 떨어질수록 크고 노골적인 것이 풀린다(불안 → 공포 → 붕괴).
- **간격:** 평온 16~28초, 불안 10~18초, 공포 6~12초, 붕괴 4~8초에 하나. 같은 것이 연달아 나오지 않는다.
- **눈은 눈꺼풀로 깜빡인다:** 그림을 납작하게 누르지 않는다. 눈 주변 피부·주름은 그대로 있고 눈꺼풀만 내려온다(뜸 → 반쯤 → 감김, 한 장에 1/12초). 사라지기 직전에는 눈을 감는다.
- **거울이 가려진 날(4일차~)에는 거울 현상이 없다:** 단발 마네킹이 거울 앞에 서기 때문.
- 움직임 줄이기 설정이면 노이즈가 고정되고, 핏자국이 흘러내리지 않는다.

## 움직임 (`scene.ts`의 `apparitionAnim`)
도트 게임답게 **초당 12장으로 끊어** 움직이고, 반투명 대신 **체커 무늬로 스민다**(팔레트 밖 중간색이 생기지 않게). 움직임 줄이기 설정이면 움직이지 않고 그대로 보인다.

| 괴현상 | 움직임 |
|---|---|
| 문 유리 너머 얼굴 | 오른쪽 문짝 유리가 어둡게 꺼짐 → 그 안에서 뜬 눈의 얼굴이 스며 나옴 → 눈꺼풀로 한 번 깜빡임 → 눈을 감고 사라지고 유리가 돌아옴 (유리 한 칸 밖으로는 그리지 않는다) |
| 바닥의 손 | 바닥에서 천천히 올라옴 → 손가락이 경련하듯 떨림 → 휙 꺼짐 |
| 선반 손가락 | 선반 가장자리로 기어 올라옴 → 툭 미끄러져 사라짐 |
| 거울에 붙은 얼굴 | 스며 나옴 → 유리에 쾅 부딪히듯 한 번 커짐 → 스며 사라짐 |
| 거울 속 긴 머리 여자 | 멀리 서 있다가 끊기듯 두 번 다가옴(다가오는 장면은 안 보이고 위치만 바뀜) → 툭 사라짐 |
| 거대한 두 눈 | 감긴 채 스며 나옴 → 눈꺼풀이 반쯤 → 다 올라감 → 한 번 깜빡임 → 감긴 채 스며 사라짐 |
| 어둠 속 여러 눈 | 감긴 채 스며 나와 한꺼번에 뜸 → 숨 쉬듯 부풀었다 줄었다 하며 한 번 깜빡임 → 모두 감기고 사라짐 |
| 핏자국 | 손자국에서 아래로 흘러내림 |
| 노이즈 사람 | 지직거리며 한두 도트씩 흔들림 |
| 마네킹 움찔 | 맨 왼쪽 마네킹이 고개를 확 돌렸다 원래대로 (0.45초) |

확인용: `?test=1`로 열고 콘솔에서 `__renderer.debugApparition('doorGapEyes', 1.1)`.
