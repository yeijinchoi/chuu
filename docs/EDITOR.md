# 문구 편집기

게임의 **모든 글**(손님 대사·재방문 대사·반응·속마음·선택 대화·연락처·수칙·문자 템플릿·상품·UI 문구·엔딩·단서 …)을 낱개 1:1로 고치는 웹 도구다. 약 1,200개.

- 주소: 배포 사이트의 `editor.html` (예: `https://jeanychoi.com/chuu/editor.html`). 로컬은 `npm run dev` 후 `/editor.html`.
- 왼쪽 묶음(손님별 · 수칙·연락처·문자·상품 · UI·시스템 문구)을 고르거나 위에서 검색한다. 칸마다 한국어 이름과 경로 id(`customers/hanyeoreum/lines/opening`)가 붙는다.
- 고치면 즉시 이 브라우저에 자동 저장된다(다른 기기·브라우저로는 가지 않는다). 상단에 "저장됨 시각"이 보이고, 저장이 막히면 빨간 경고가 뜬다.
- 수정한 칸은 금색 줄로 표시되고 "원문으로"로 되돌릴 수 있다. `{name}` 같은 자리표시자가 빠지거나 지문의 `> `가 없어지면 경고한다.

## 결과를 게임에 반영하는 법
1. **미리보기**: "게임에서 미리보기"를 누르면 게임이 새 탭에서 `?edited=1`로 열리고 수정 내용이 적용된다(왼쪽 아래에 "수정본 미리보기" 표시). 저장본(진짜 게임 데이터)은 바뀌지 않는다.
2. **저장소에 반영**: "패치 복사"(또는 "패치 내려받기")로 얻은 패치를 전달하면 된다. 직접 적용하려면:
   ```bash
   npx vite-node tools/apply_text_patch.ts 패치.json --dry   # 시험
   npx vite-node tools/apply_text_patch.ts 패치.json         # 적용
   ```
   적용 전에 패치의 `before`(원문)가 지금 파일과 같은지 확인하고, 다르면 그 칸은 건너뛴다.
   또는 "수정된 JSON 내려받기"로 받은 파일을 `src/data/`에 덮어쓴다.
3. "불러오기"로 패치를 다시 올려 이어서 고칠 수 있다(못 찾은 경로는 알려 준다).

## 알아 둘 것
- 손님 **이름**을 바꾸면 `contacts.json`(연락처 이름)·엔딩 문구 속 이름은 따로 고쳐야 한다.
- 대사 앞의 `> `는 지문(장면 묘사) 표시다. 지우면 대사로 나온다.
- 편집 대상에서 뺀 값: id, 카테고리·색, 인사 선호, 스프라이트, 수칙 번호·판정 필드, 수치(예산·시각), 단서·플래그 id.
- 구현: `src/editor/textmap.ts`(낱개 추출·경로·패치, DOM 없음), `store.ts`(저장·게임 데이터 연결), `main.ts`(화면). 테스트 `tests/core/textmap.test.ts`.
