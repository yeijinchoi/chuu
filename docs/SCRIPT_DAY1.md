# 텍스트 콘티 — 1일차 (상세) + 2~3일차 (줄거리)

> 기준 문서: `GDD.md`(규칙·수치), `CUSTOMERS.md`(손님·수칙). 이 문서는 **화면에 나오는 모든 글과 연출 순서**를 정한다.
> 구현 시 대사는 이 문서에서 데이터 파일(`src/data/*.json`)로 옮긴다. 기존 데이터에 없는 대사는 ★로 표시했다.

## 0. 표기 규칙

| 표기 | 뜻 |
|---|---|
| `S03` | 장면 번호 |
| **[화면]** | 장면·조명·스프라이트 변화 |
| **[UI]** | 대화창 밖 UI(HUD, 폰, 쪽지, 카드) |
| **[SFX]** | 효과음 자리(구현은 이벤트 이름만) |
| **[연출]** | 흔들림, 반전, 깜빡임 등 |
| `이름: 대사` | 손님·인물 대사. 대화창 이름표에 이름 |
| `> 지문` | 이름표 없는 서술(`speaker: null`) |
| `(속마음) …` | 주인공의 생각. 기울임 없이 `mist` 색, 이름표 없음 ★신규 표현 |
| `① ② ③ ④` | 선택지. 화면 오른쪽 선택지 패널, 키 1~4 |
| `→` | 선택 결과 |
| `{조건}` | 분기 조건 |
| ★ | 기존 데이터에 없는 새 대사(구현 때 추가) |

**새 대사 필드 (★ 반응 대사)**: 손님마다 아래 반응을 추가한다. 없으면 `strings.ko.json`의 공통 반응을 쓴다.
`enter`(입장 지문) · `greet.match` · `greet.mismatch` · `propose.perfect` · `propose.deptOnly` · `propose.wrong` · `propose.overBudget` · `close.tryOn` · `close.box` · `close.checkout` · `regular.accept` · `regular.decline` · `leave`

**톤 규칙**
- **서윤 호칭**: 서윤을 아는 손님은 "서윤 씨" 또는 "담당자님"으로만 부른다("서윤이", "그 아가씨" 금지). 점장 로즈의 쪽지만 예외로 "서윤이"라고 쓴다. 동생 한서진은 "언니".
- 주인공 속마음은 짧고 평범하다. 겁먹어도 존댓말 영업 말투는 무너지지 않는다. 무서운 건 상황이지 주인공의 비명이 아니다.
- 새벽 대사는 문장을 짧게 끊는다. 지문은 감각 하나(냄새, 온도, 소리)만 쓴다.
- 숫자·시각은 항상 Mono 글꼴(₩, HH:MM).

## 1일차 상세 콘티

### S00 · 타이틀
**에셋**: `public/art/brand/logo-full.png`(엠블럼 + MAISON LUMIÈRE, 200×205 도트), `public/art/brand/emblem.png`(엠블럼만, 96×138). 원본은 `docs/concept/brand/logo-a.png`, 변환은 `tools/pixelize_logo.py`.

**연출 순서** (전체 약 4초, Space/클릭/Enter로 바로 끝까지)
1. 검은 화면 0.4초.
2. 금색 필리그리 프레임(주 프레임, `brass` 계열 밝게)이 화면 가운데에 그려진다 — 모서리 장식부터 선이 이어지듯 0.6초.
3. 프레임 안 위쪽에 **브랜드 로고**(logo-full)가 나타난다. 진주에 `paper` 반짝임 1회.
4. 로고 아래, 스마트폰 메시지 말풍선 자리에 **입력 중 "•••" 말풍선**(받은 말풍선 모양, 왼쪽 꼬리)이 1.2초 깜빡인다. **[SFX]** `phone_buzz` 1회.
5. "•••"가 사라지고 받은 말풍선으로 제목이 도착한다: **「방문 일정을 말씀해 주세요.」** (Galmuri14, 말풍선 안 두 줄 허용). 말풍선 위 작은 회색 글씨로 보낸 사람 `메종 뤼미에르`, 아래에 `오전 9:00`.
6. 그 아래 선택지: `[Enter] 출근하기` · `[C] 이어하기`(저장 데이터가 있을 때만. 손상되었으면 "저장 데이터를 읽지 못했어요").
- 모바일: 같은 구성을 세로로(프레임 폭 = 화면 폭 − 32), 선택지는 48px 버튼.
- 새벽 진행 저장이 있으면(2일차 이후) 같은 연출에서 말풍선 보낸 사람이 `나`로 바뀌는 변주를 나중에 넣는다.

**업무폰 배경화면**: 잠금·홈 화면 바탕을 `shadow`로 하고, 가운데에 엠블럼(emblem.png)을 둔다. 바탕에 아주 옅은 퀼팅 마름모(`dusk` 1px 선). 새벽(검은 수첩 이후)에는 엠블럼이 mood 규칙대로 회색으로 녹슨다.

**이름 입력**
> 오늘부터 메종 뤼미에르에서 일하게 되었다. 명찰에 이름을 적는다.

**[UI]** 입력칸(최대 6자, 기본값 `신입`) · `[Enter] 확인`

### S00a · 오프닝 (타이틀의 "출근하기" 뒤)
> 대사 원문은 `strings.ko.json`의 `opening.steps`(문구 편집기로 고칠 수 있다). 화면: 검은 바탕 위 장면 자막 · 문자 대화 창 · 지문. 문자는 "입력 중" 뒤에 저절로 오고, 지문은 Space/클릭을 기다린다. Esc는 이름 묻는 곳까지 건너뛴다.

1. 자막 "밤 11시 40분 · 퇴근길 지하철". 주인공은 다른 명품 브랜드 매장의 5년 차 어드바이저.
2. **한서윤**(5년 전 같은 매장 동료)의 문자: 그만둔다, 후임으로 당신을 추천했다, "어렵지 않아요. 수칙만 지키면 돼요." → "그리고 새벽에는"에서 입력 중이 멈추고 끊긴다. 답장은 읽히지 않는다.
3. 자막 "사흘 뒤 · 오전 9:00". **메종 뤼미에르(로즈)**의 문자 "방문 일정을 말씀해 주세요."(타이틀의 그 문자) → 월요일 출근 → 로즈가 이름을 묻는다.
4. 답장 칸에 이름(최대 6자)을 적어 보낸다 → "{name} 씨. 월요일에 봬요." → S01로.

복선: 서윤의 "어렵지 않아요"는 마지막 밤의 "어렵지 않아요. 그냥 '네'라고 말하면 돼요"와 짝이다. 주인공이 서윤을 아는 사람이므로 S01 속마음은 "서윤 씨가 쓰던 휴대폰이구나. …정말 그만뒀구나."

### 공통 응대 흐름 (모든 손님)
1. **입장**: 문 열림(오후) / 문 소리 없음(새벽) → 손님이 자기 카테고리 쪽을 2초 둘러본다 → 카운터 앞으로 → `enter` 지문 → 첫 대사.
2. **[UI]** 상단 단계 표시 `인사 · 니즈 · 제안 · 클로징`, 하트 5칸 등장.
3. **인사** ① 밝게 인사한다 ② 정중히 목례한다 ③ 바로 상품을 소개한다 → `greet.match`/`greet.mismatch` + 하트 변화 반짝임.
4. **니즈 파악** (넷 중 둘, 쓴 질문은 비활성 "이미 물어봤어요") ① 찾으시는 품목이 있으세요? ② 어떤 자리에서 쓰실 건가요? ③ 생각하신 예산이 있으세요? ④ 가만히 관찰한다
   - 답변이 나오면 **[UI]** 폰 아이콘에 작은 점 + 토스트 `고객 카드에 기록했어요 · 예산` (2초).
5. **제안**: 상품 카드 3장(64×64 아이콘, 이름, 색칩, 가격/환산가) → 고르면 `propose.*` 반응.
5-1. **대접**(VIP만): 인사 직후 ① 탄산수 ② 초콜릿 ③ 아무것도 내지 않는다 → 취향 반응, 카드에 기록.
6. **클로징** ① 시착을 권한다 ② 빨간 상자에 포장한다 ③ 금색 상자에 포장한다 ④ 바로 결제를 안내한다 → `close.*` 반응.
7. **판정**: 성공 → `success` + **[SFX]** `register` + HUD 금액이 2프레임 튄다 / 실패 → `fail`.
8. **단골 제안**(호감 85 이상, 새벽은 수칙 지킨 성공) ① 단골 등록을 권한다 ② 그냥 보내 드린다 → `regular.*`
9. **퇴장**: `leave` 지문 → 손님 스프라이트 퇴장.
